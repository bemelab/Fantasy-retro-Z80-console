ZL-80 virtual console

A Z80 computer clocked at 4 MHz, with real instruction timings, 64 KB of memory, a choice of display modules (SSD1306 OLED, ST7735 TFT, Nokia 5110 LCD or a virtual screen), and its own language, ZL, that compiles to real Z80 machine code.

Press Run to start.






Language reference



x = a + bAlso - and &. Values are 8-bit (0–255), so 0 − 1 gives 255.


rndRandom byte, usable like a number: x = rnd & 31


key kReads keys: 1 left, 2 right, 4 up, 8 down, 16 fire (combined as bits).


plot x y cSets a pixel to color 0–15. The range depends on the display: virtual 64×64, SSD1306 128×64, ST7735 128×160, Nokia 5110 84×48. Monochrome displays show every color above 0 as on.


clsClears the screen.


wait nPauses n frames (60 per second).


if a < b … else … endCompares: < > <= >= == !=


while a < b … endLoop. Use while 1 == 1 to loop forever.


dim a 4Declares an array (up to 256 items). Use a[i] = 5 and x = a[i]. The index is a number or variable.


label nameMarks a place in the program.


goto nameJumps to a label.


gosub name … returnCalls a subroutine; return comes back to the line after the call.


dim g 8 8Two-dimensional array, used as g[row][col]. The second size must be a power of two and the total at most 256.


for i = a to b … endCounts i from a up to b − 1.


inc v / dec vAdds or subtracts 1.


x = a | bBitwise or. ^ is xor.


fill cFills the screen with color c.


get v x yReads the color of pixel (x, y) into v.


beep nPlays a short tone; higher n is higher pitch.


stopEnds the program.


def n r0 … r7Defines 8×8 sprite n (0–31) from eight row bytes; bit 7 is the left pixel. Hex like 0x3C works everywhere.


crtc r vWrites CRTC register r (0–31). R1 columns shown, R6 rows shown, R9 scan lines per row minus 1, R10/R11 cursor shape and blink, R12/R13 start address (hardware scroll), R14/R15 cursor address. R18/R19 set the 6545 update address and R31 writes a character there.


poke hi lo vWrites byte v to the 16-bit address hi×256 + lo. peek v hi lo reads it. Use plain values.


vaddr hi lo / vdata v / vreg r vTMS9918A: set the VRAM address, write a VRAM byte (address auto-increments), write VDP register r.


vdg m / vbase p / vprint col row "TEXT"MC6847: mode byte (bit 0 graphics, bits 1–3 mode, bit 4 color set), video RAM page, text into the 32×16 screen. Default is mode 13: 128×192, 4 colors.


plot / get / cls / fillWork on every display. The TMS9918A and MC6847 keep pixels in their own memory layouts, and the TMS9918A allows two colors per 8-pixel row, so colors can clash.


ay r v / ayget v rAY-3-8910 sound chip. Registers: R0–R5 tone periods (12 bit), R6 noise period, R7 mixer (bit 0–2 tone off, 3–5 noise off, a 1 disables), R8–R10 volume (bit 4 = use envelope), R11/R12 envelope period, R13 envelope shape (0–15), R14 port A (keyboard bits).


note ch nSets tone channel ch (0–2) to MIDI-style note n (69 = A 440 Hz).


vreg r v, vaddr hi lo, vdata v, vrd hi lo, vget v, vstat v, vfont, vtext "TEXT"TMS9918A in full: write registers R0–R7, set VRAM address for writing or reading, write or read VRAM, read the status register (bit 7 frame, bit 6 fifth sprite, bit 5 collision), load a character set into the pattern table, write text characters. All four modes and 32 sprites work.


data name v1 v2 …Fills an array from a list of values (declare it with dim first), for example data root 45 41 48 43.


crtcget v rReads CRTC register r (R12–R17) into v.


tcolor aText attribute: low nibble is the text color, high nibble the background (0x0A is light green on black).


locate col rowMoves the text position (row × R1 + col). Also moves the cursor.


tprint "TEXT"Writes characters into text RAM at the text position.


thex v / tclsWrites v as two hex digits / clears the text screen.


sprite n x y cDraws sprite n in color c. Color 0 erases it.


print x y c "TEXT"3×5 font, 4 pixels per character. Letters (shown uppercase), digits and . : - + ! ? , = /


seg x y c vShows v as two hex digits on a seven-segment display (11×9 pixels). It erases the old digits first.


; textComment. It also appears in the assembly listing.




Memory map: 0x0000 program, 0x4000 variables, 0x8000 screen. Port 0 is the keyboard, port 1 is the random generator.
